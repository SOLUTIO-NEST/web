# Tree반 커리큘럼

> 깊이 있는 실력을 키우는 단계입니다.

## 개요

Tree반은 고급 알고리즘과 대회 수준의 문제를 다루는 반입니다.  
백준 기준 **골드 ~ 플래티넘** 난이도의 문제를 중심으로 학습합니다.

---

## 주차별 학습 내용

### 1주차 — 트리와 고급 그래프

- 트리의 성질과 순회
- 최소 스패닝 트리 (MST)
- 최단 경로 (Dijkstra, Floyd-Warshall)

### 2주차 — 고급 동적 프로그래밍

- 비트마스크 DP
- 트리 DP
- 구간 DP

### 3주차 — 문자열 알고리즘

- KMP 알고리즘
- 트라이 (Trie)
- 해싱 기법

### 4주차 — 세그먼트 트리와 쿼리

- 세그먼트 트리
- 느리게 갱신되는 세그먼트 트리 (Lazy Propagation)
- 오프라인 쿼리 처리
