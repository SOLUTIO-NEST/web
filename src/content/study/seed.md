# Seed반 커리큘럼

> 프로그래밍의 씨앗을 심는 단계입니다.

## 개요

Seed반은 알고리즘 문제 해결의 기초를 다지는 반입니다.  
백준 기준 **브론즈 ~ 실버** 난이도의 문제를 중심으로 학습합니다.

---

## 주차별 학습 내용

### 1주차 — 입출력과 자료형

- 표준 입출력 처리
- 정수, 실수, 문자열 자료형
- 형변환과 연산자

### 2주차 — 조건문과 반복문

- if / else / else if 분기
- for, while 반복문
- 중첩 반복과 break / continue

### 3주차 — 배열과 문자열

- 1차원 배열 선언 및 순회
- 문자열 처리 기법
- 아스키 코드 활용

### 4주차 — 함수와 재귀

- 함수 정의와 호출
- 매개변수와 반환값
- 재귀 함수의 기본 개념
